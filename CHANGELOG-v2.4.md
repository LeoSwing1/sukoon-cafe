# Sukoon Cafe v2.4 — Dine-in default and cleaner order panel

- Customer menu now defaults to **Dine in** on a fresh visit.
- Dine-in remains selectable without a QR token so customers can see the intended default; submitting a dine-in order still requires a valid table QR token and gives a clear prompt otherwise.
- Removed the oversized non-interactive “Let's make it delicious” heading from the cart panel to keep the ordering controls compact.
- Takeaway remains available as the second option.
- No database migration or seed is required.
